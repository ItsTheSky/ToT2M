# Pack TotM Editor

Tout le travail réalisé jusqu'ici sur le modding de Tomb of the Mask 1.2.28, sans les APK.

- `PROMPT.md` : la mission à donner à Claude Code.
- `CLAUDE.md` : tout ce qu'on sait (Claude Code le lit automatiquement).
- `editor/` : prototype fonctionnel de l'éditeur.
- `level-tools/` : outil PC `totm_levels.py`.
- `reference/` : dump IL2CPP, désassemblages, niveaux, sprites, sources Tiled des devs, scripts d'analyse.

Démarrage :
1. Copier `tomb-of-the-mask-1-2-28.apk` dans `input/`.
2. Ouvrir le dossier dans Claude Code.
3. Lancer : « Lis PROMPT.md et réalise la mission. »
