# reference/ (non versionné)

Ce dossier contient des données extraites du jeu (dump IL2CPP, sprites, niveaux, cartes Tiled des devs).
Elles ne sont **pas** dans le dépôt Git (dépôt public, contenu du jeu). Copie ici le dossier `reference/` du pack
(`il2cpp/`, `notes/`, `levels/`, `dev_tmx/`, `assets/`). Seul `scripts/` est versionné.

Les tests (`editor/test/run_tests.sh`) utilisent `reference/levels/` et `reference/assets/` s'ils sont présents.
